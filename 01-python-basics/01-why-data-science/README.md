## What I Learned

Python is a general-purpose programming language widely used in
Data Science because of its versatility and extensive ecosystem
of third-party libraries.

Python can be used for:

- Data analysis
- Data visualization
- Data processing
- Prototyping
- Artificial Intelligence
- Machine Learning

## Python in Data Science

Python has several libraries specifically designed for working
with data:

- NumPy — numerical computing
- Pandas — data manipulation and analysis
- Matplotlib — data visualization

## Key Concept

SQL is very useful for querying and extracting data from databases,
but Python allows us to go further by processing, analyzing,
manipulating and visualizing the extracted data.
